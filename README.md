ToDo-List
A clean to-do list app built with vanilla JavaScript, HTML and CSS — no framework, no build step.
Features
Add a task with the button or the Enter key
Mark tasks complete / incomplete
Delete a task, or clear all completed tasks at once
Filter tasks — all, active, completed
Live task counter
Tasks are saved in localStorage, so they are still there when you reopen the page
How to run
Just open index.html in your browser. That's it.
